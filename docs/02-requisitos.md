## Requerimientos Funcionales
- El sistema permitirá ingresar prompts.
- El sistema deberá procesar prompts.
- El sistema deberá permitir al estudiante realizar preguntas relacionadas con el PDF adjuntado y con la programación.
- El sistema deberá recuperar lo más relevante solicitado por el usuario en el prompt leyendo la guía.
- El sistema deberá responder en base a la información más relevante recuperada.
- El sistema deberá mostrar al estudiante una respuesta basada en la información recuperada de la guía.

## Requerimientos No Funcionales
- El sistema deberá ser seguro.
- El sistema deberá responder en el menor tiempo posible.
- El sistema deberá prohibir preguntas no relacionadas con los PDF adjuntos y con el tema de programación.
